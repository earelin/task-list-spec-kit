# Contracts: Frontend Scaffolding

**Date**: 2025-12-25
**Feature**: 002-frontend-scaffolding

## Overview

The frontend scaffolding does not define API contracts as it focuses on project structure
and tooling. This directory is created as a placeholder for future feature contracts.

## Future Contracts

When implementing features that require API communication with the backend, contracts
will be added here:

- `api-health.yaml` - Health check endpoint contract (integration with backend)
- `api-tasks.yaml` - Task CRUD operations (future feature)

## Contract Format

Contracts will use OpenAPI 3.1 specification format for REST APIs.
